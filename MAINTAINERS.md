## 2. Responsibilities

Maintainers are responsible for:

### Code Quality
- Reviewing and merging pull requests
- Ensuring code follows project style and architecture
- Maintaining test coverage and CI stability

### Releases
- Managing version bumps using bump2version
- Running release pipelines (local or GitHub Actions)
- Ensuring changelogs and documentation are updated

### Community
- Responding to issues and discussions
- Enforcing the Code of Conduct
- Supporting contributors and new maintainers

### Governance
- Participating in decision-making
- Voting on major changes when needed
- Updating governance and policy documents

---

## 3. Expectations

Maintainers are expected to:

- Communicate respectfully and constructively
- Provide timely feedback (within 72 hours when possible)
- Keep the project stable and secure
- Collaborate openly and transparently
- Document major decisions

---

## 4. Adding New Maintainers

A contributor may be invited to become a maintainer if they:

- Demonstrate consistent, high‑quality contributions
- Show strong understanding of the codebase
- Communicate clearly and respectfully
- Are approved by existing maintainers

---

## 5. Removing Maintainers

A maintainer may be removed if they:

- Become inactive for an extended period
- Violate the Code of Conduct
- Act against project interests
- Fail to collaborate constructively

Removal requires a majority vote of active maintainers.
