# Project Roadmap

This roadmap outlines planned features, improvements, and long‑term goals for the project.  
Timelines are approximate and may shift based on community feedback and priorities.

---

## 1. Near‑Term Goals (0–3 months)

### 🔹 Packaging & Release Automation
- Finalize bump2version integration
- Improve Makefile release targets
- Expand GitHub Actions CI/CD
- Add automated changelog generation

### 🔹 Documentation
- Improve README with examples and visuals
- Add API reference documentation
- Add usage guides and tutorials

### 🔹 Code Quality
- Increase test coverage
- Add type hints across the codebase
- Improve error messages and validation logic

---

## 2. Mid‑Term Goals (3–6 months)

### 🔹 Feature Enhancements
- Expand TextFSM template validation
- Add template auto‑fix suggestions
- Add CLI improvements and subcommands
- Add configuration profiles for different vendors

### 🔹 Developer Experience
- Add logging improvements
- Add debug mode for template parsing
- Improve exception hierarchy

### 🔹 Documentation Site
- Build a full documentation site (MkDocs or Sphinx)
- Add examples, diagrams, and best practices
- Publish to GitHub Pages

---

## 3. Long‑Term Goals (6–12 months)

### 🔹 Ecosystem Expansion
- Create plugin system for custom extractors
- Add support for additional parsing engines
- Provide integration with automation frameworks

### 🔹 Performance & Scalability
- Optimize parsing performance
- Add benchmarking suite
- Improve memory usage for large templates

### 🔹 Community Growth
- Encourage external contributions
- Add more maintainers
- Host community discussions and roadmap planning

---

## 4. Vision

The long‑term vision for this project is to become:

- The most developer‑friendly TextFSM toolkit
- A reliable, well‑documented parsing engine
- A foundation for automation, network tooling, and data extraction workflows
- A community‑driven project with clear governance and predictable releases
