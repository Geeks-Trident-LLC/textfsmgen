# Security Policy

We take the security of this project seriously and appreciate responsible disclosure of vulnerabilities.

---

## 1. Supported Versions

Security updates are provided for the latest released version of the project.

Example:

- `0.x` — Supported  
- Older versions — Not supported

---

## 2. Reporting a Vulnerability

If you discover a security issue, please report it privately.

Contact:
- Email: security@geekstrident.com
- Alternative: open a private GitHub security advisory

Please include:

- A clear description of the issue
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fixes (optional)

We will acknowledge your report within **72 hours**.

---

## 3. Disclosure Process

Once a vulnerability is reported:

1. We confirm the issue.
2. We assess severity and impact.
3. We prepare a fix and test it.
4. We release a patched version.
5. We publish a security advisory.

We strive to resolve issues within **14 days**, depending on complexity.

---

## 4. Scope

This policy applies to:

- Source code in this repository
- Release artifacts published to PyPI
- Documentation and configuration files

It does **not** apply to:

- Third‑party dependencies
- User‑specific deployment environments

---

## 5. Responsible Disclosure

We ask that you:

- Do not publicly disclose vulnerabilities before a fix is released
- Do not exploit vulnerabilities
- Do not access or modify data you do not own

Thank you for helping keep this project secure.
