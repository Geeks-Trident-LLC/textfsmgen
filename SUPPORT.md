# Support Guide

Thank you for using this project!  
This document explains how to get help, ask questions, and request features.

---

## 1. Where to Get Help

### 🐛 Bug Reports
Open an issue on GitHub:

https://github.com/Geeks-Trident-LLC/textfsmgen/issues

Include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details

---

### 💡 Feature Requests
Submit a feature request via GitHub Issues.

Provide:

- Problem description
- Proposed solution
- Alternatives considered

---

### ❓ General Questions
Use GitHub Discussions (if enabled) or open a “Question” issue.

---

## 2. Response Expectations

We aim to respond within:

- **72 hours** for general issues
- **48 hours** for bug reports
- **24 hours** for security issues (see SECURITY.md)

---

## 3. Commercial Support

For enterprise or commercial support:

Email: support@geekstrident.com

## 4. Self‑Help Resources

- README.md
- CONTRIBUTING.md
- RELEASE.md
- CHANGELOG.md
- GitHub Discussions (if enabled)

---

## 5. Before Opening an Issue

Please check:

- Existing issues  
- Closed issues  
- Documentation  
- Recent releases  

This helps avoid duplicates and speeds up resolution.

We appreciate your feedback and support!
